# ADR-027：账号化双人协同与单视角录制

日期：2026-10-07。状态：Accepted。范围：`Kai4nIS4n/code-tape` 个人功能升级。

维护者已明确要求根据 `docs/CodeTape-功能升级Spec.md` 完成开发，此决策把原 P1+ 只读面试扩展为双向编辑。

采用 Yjs/Y.Text + Monaco，独立已鉴权的 collaboration WebSocket 负责正文合并、服务器持久化和 ACK；WebRTC 继续承载音视频，DataChannel 继续承载候选人录制观察流。候选人唯一 EventBus/RecordingClock 保持回放确定性，晚到的离线修改记录在其被候选人观察到的时刻，不回填媒体历史。

新增用户名/密码账号、标准 JWT 和可撤销 session。SQLite 与私有磁盘分别保存元数据/CRDT 和录制资产，播放 grant 的权限检查覆盖实际 GET、HEAD、Range 及缩略图。旧匿名身份不能自动认领新账号资源。

Schema 使用 0.2.0，五文档、视图事件与运行结果显式关联；0.1.0 原始 checksum 验证完成后才转换运行时结构。虚拟时间轴、字幕历史定位、连续 Seek 保护及按需加载遵循 Spec。

所有自动合并、推送及 PR 目标均在个人 fork，测试与性能按真实结果验收。继续保留本地离线录制、ZIP 和静态安全回放；不扩展到多人录制合流、Python 执行或后端沙箱。
